# 每日地量准备启动股 TOP 20

在 PULSE 侧栏打开「地量严选」。接口为 `GET /api/strategy/ground-volume-top20`，支持 `slot=latest|14:45|15:15`。页面默认显示综合分 TOP 20，可以在这 20 行内按综合分、T+5 胜率、T+5 平均历史收益或最小回撤重排。换序保留原综合排名。14:45 是累计成交量盘中预筛，15:15 是最终日线确认。相邻榜单无需重合，合格不足 20 只时展示实际数量。[深交所主板交易时段说明](https://investor.szse.cn/institute/rules/t20230629_601434.html)

## 接入授权数据

当前仓库的普通行情源没有全量历史时点筹码、扣非净利润、解禁和风险标记。模块通过尚需配置的本地只读快照目录接收授权数据。设置 `PULSE_GROUND_VOLUME_DIR` 后，由现有服务进程在深交所日历确认开市后的 14:45 和 15:15 读取快照，并在同一 SQLite 缓存中分时点归档。快照需要由已有的授权数据管道生成。未配置时，接口返回 `not_configured`。缺包或包损坏时，在 14:59、16:00 前按分钟重试，不改写有效历史快照。前端区分待运行、正在运行、空榜与旧榜。如用于 Railway，需要把授权输入目录挂到现有可访问持久存储，并单独验收输入管道。

按 Asia/Shanghai 日期和时点放置文件，例如：

```text
$PULSE_GROUND_VOLUME_DIR/
  2026-11-20/
    1445.json
    1445.ndjson
    1515.json
    1515.ndjson
```

先写完整 `.ndjson`，再以原子重命名发布同名 `.json` 清单。完整批次发布后保持不可变。清单字段如下。

| 字段 | 约束 |
| --- | --- |
| `schema_version` | 整数 `1` |
| `as_of` | 带时区 ISO 时间，位于相应的目标分钟内。晚到文件仍应保留其原始数据时点。 |
| `source` | 可公开显示的数据来源名称。勿填写路径、认证信息或带密钥的 URL。 |
| `sessions` | 606 至 800 个递增、不重复的交易日（`YYYY-MM-DD`），结尾为扫描交易日。应由交易所日历生成，保留个股停牌和缺数的全市场交易日。 |
| `universe_size` | NDJSON 中的实际标的数，1 至 6000。生产接入应覆盖沪深主板全量股票，不能以成交额等预排名截断后宣称全市场。 |

NDJSON 每行是一个 `{"code":"sh600000","name":"名称","sector":"行业","bars":[...]}` 对象，股票代码唯一。每只股票的 `bars` 可以缺日，不能有重复日期。每个时点按当时已知信息提供如下字段：

| 字段 | 含义和计量 |
| --- | --- |
| `day`, `known_at`, `quote_at` | 交易日、该行数据的点时可得时间和行情来源时间，后两者均使用带时区 ISO 时间。历史日线有效窗口为当日 15:00–15:15:59。当前行报价时点不能晚于 `known_at`。盘中报价最多滞后 120 秒，收盘包要求行情时点不早于 15:00。 |
| `open high low close adj_factor` | 未复权开高低收（元），及用于把价格转成同一经济口径的正数复权因子。盘中 `close` 是最新价。应提供一致的复权因子定义，避免公司行动造成虚假收益。 |
| `volume amount turnover pct float_cap` | 成交量（股）、成交额（元）、换手率（百分点）、当日涨跌幅（百分点）、流通市值（元）。盘中使用截点累计值，未经外推。 |
| `listed_sessions risk_warning suspended limit_up limit_down` | 当时已上市的交易日数、风险警示及停牌状态（布尔）、该交易日真实上下限价（元）。使用来源提供的限价。 |
| `deducted_profit` | 截止当时已披露的最近两个可比单季度扣非净利润（元）。若原披露为年内累计，数据管道应先转换，且不能使用事后才披露的值。 |
| `unlock_float_pct_30d` | 截至 `known_at` 已披露、未来 30 自然日内计划解禁股数相对当前流通股的百分比，无已知解禁为 0，未知为 null。 |
| `chip90_pct` | 90% 筹码区间宽度相对区间中点的百分比，计算式 `100 × (P95−P5) / ((P95+P5)/2)`。 |
| `main_net dark_net` | 当时已知主力资金或拆单净资金（元）。至少一路有效，可缺一路。缺失为 null，无流入为 0。 |

一字板使用数据源限价和 OHLC 判定，避免按估算涨跌停比例误判。缺失关键字段的标的不入榜。历史数据应保留每个历史信号日的公告、风险状态、价格和筹码断面。时间戳校验只能发现结构错误，授权管道仍要负责数据真实性、完整性、授权用途和时间对齐。

## 筛选、回测和计分

- 地量使用前 120 日的经验分位（小于等于当前成交量的占比），或当前成交量为前 60 日最大值的至多 25%，两种情况下均须满足 5/60 均量比不超过 0.50。近 5 日振幅使用此前复权收盘作分母。均线用当时可见的同口径价格。
- 连续亏损定义为最近两个可比单季度均为负。大额解禁定义为未来 30 日内累计达到流通股的 5%。近 20 日回撤使用滚动复权收盘。支撑须低于现价、距离不超 5%，且前 20 日至少两次低点进入支撑上方 1.5% 范围。
- MACD 使用 EMA(12,26,9)，三次负柱缩短或在 DIF/DEA 绝对值均不超过现价 0.5% 时出现金叉。RSI 使用 Wilder RSI(6)，前一日不高于 30 且今日向上。OBV 比较前后两个相邻五日区间各自低点，要求价创新低而 OBV 抬升。小幅净流入定义为有效资金净流入占成交额大于 0、不超过 3%。至少满足两项。
- 回测对最近 485 个交易日重复使用同一收盘筛选规则，最早信号以前的 120 日仅作指标预热。比较 T+1 开盘至 T+1/T+3/T+5 收盘的未扣成本收益。T+1 当日买入后收盘仅做账面估值，T+3 和 T+5 是模型退出点。入口缺价、停牌、涨停开盘，以及出口缺价、停牌、跌停收盘的样本不参与对应周期。14:45 当前未完成日线不会作为历史成交日。各期限单独显示有效样本。T+5 无成熟样本时不能参加排名。盈亏比为平均盈利除以平均亏损绝对值，只有单边样本时显示缺失。
- 最大回撤使用一进一出、头寸不重叠的 T+5 交易净值，按可观察的日收盘估值，缺少中间日行情时沿用最后估值。它和筛选使用的近 20 日价格最大回撤是两个指标。回测为逐标的历史事件分析，更换样本、费用或成交假设会改变结果。
- 各子项归一化后截断到 0–1：胜率按自身百分比换算后乘 35；盈利项按 `60% × 平均收益/5% + 40% × 盈亏比/3` 乘 35，缺盈亏比不加分；资金和筹码等权后乘 20，资金以 3% 成交额为满分，筹码宽度从 0% 至 15% 线性降分；T+5 历史最大回撤从 0% 至 12% 线性降分后乘 10。综合分相同按胜率、平均收益、回撤和股票代码确定名次。
- 观察价位以当前收盘或盘中最新价为参考，区间下界取支撑、参考价下浮 1% 和止损位上方一档中的较高值。S1/S2 分别为参考价上浮 3%/6%。理论止损为信号日低点与参考价下浮 3% 之较高者。单票规则上限 20%。模块不接券商委托或修改账户仓位。

查阅本地接口时可分别请求 `?slot=14:45` 和 `?slot=15:15`。单元测试使用完整的合成快照跑通调度与 API，仅作为功能验收。

# Pulse A 股智能盯盘终端

Windows 本地运行的 A 股行情工作台。FastAPI 提供数据接口和 WebSocket，React、TypeScript、Vite 与 ECharts 构建前端。首次进入默认使用演示模式。前端随 ZIP 提供编译成品。

## Workspace 开发

项目根目录为 `pulse-a-share`。先安装 `backend/requirements.txt`，然后在项目根目录运行 `python -m backend.launch --no-browser`，浏览器访问 `http://127.0.0.1:8765`。开发前端时，可在另一个终端进入 `frontend`，运行 `npm ci` 与 `npm run dev`。Vite 将 API 与 WebSocket 转发到本地后端。

## Windows 启动

1. 将 ZIP **完整解压**到可写目录，保留子目录结构。
2. 安装 Python 3.11 或更新版本。在 Windows 安装界面勾选 Add Python to PATH，或者确保终端可运行 `py -3`。
3. 双击 **启动盯盘台.bat**。脚本在项目中建立 Python 虚拟环境，首次联网安装依赖，服务就绪后自动打开浏览器。
4. 访问 [http://127.0.0.1:8765](http://127.0.0.1:8765)。点击「真实」开始访问行情数据源。关闭启动窗口可停止服务。
5. 仅接受本机回环连接和同源浏览器请求。端口占用时，可在命令提示符运行 `set PULSE_PORT=8766`，再在同一窗口运行启动脚本。

依赖安装成功后，演示模式可断网使用。预编译的页面已包含 JavaScript、CSS 和图表资源。改前端源码后，可用 Node.js 22.12 或更新版本在 `frontend` 内运行 `npm ci`、`npm run build`。Windows 的 Python pip 与真实数据源能否访问取决于网络及代理配置。

Linux/macOS 手动运行：

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install -r backend/requirements.txt
python -m backend.launch
```

## 操作

- 点击五大指数卡或任一自选行切换标的。分时使用 1 分钟收盘价曲线。K 线支持 1、5、15、30、60 分钟、日、周、月。日周月个股支持前复权、后复权、不复权。指数与分钟线显示原始价。
- 在自选栏输入六位股票代码。可用空格、逗号或换行批量添加，支持 CSV 导入导出。裸代码 `000001` 表示平安银行，`sh000001` 表示上证指数。
- 板块资金榜支持行业、概念、地域及今日、5 日、10 日切换。净流入与净流出各取对应方向最多 20 个。点击任一板块查看历史采集快照、实际成分和角色评分。
- 在预警面板调整日涨跌幅、换手率、短时涨跌和量比阈值。声音和通知从同一面板开启。预警与自选 CSV 可导出。右上角可全屏、刷新或设置面板宽度、排序和可见性。
- 尾盘面板从当日 14:45–15:00 内已有快照计算变化，14:57 开始显示收盘集合竞价阶段。虚拟匹配价、匹配量、未匹配量显示「未接入」。行情刷新保持适度频率，主要面板打开即可持续记录。
- 快讯与个股公告支持标记已读和打开原文。真实模式下，报价、K 线、资金、资讯和交易日历各自显示来源与状态。

## 个股追踪与条件选股

- **追踪。** 点击侧栏「追踪」并输入代码，或从走势页、选股结果加入。每种模式可追踪最多 20 只。首次有效报价是基准，后续显示相对变化和最近 60 个有效报价点。可为每只股票设价格上下限、备注或重置基准。页面打开时记录连续有效报价之间的价格穿越。价格轨迹采用行情原始报价。
- **选股。** 点击侧栏「选股」，按全市场或自选池筛选。板块详情的「筛选此板块」会带入成分范围。可指定交易所，排除 ST 和退市整理，组合涨跌幅、最新价、成交额、换手率、量比、流通市值和主力净额。区间含边界，所有已填写条件同时生效，缺失指定字段的股票跳过。结果可排序、加自选、加追踪和导出 CSV。
- 真实选股与市场广度共享完整分页快照。首次采集期间显示等待状态，后续复用最新有效数据。来源、采集时间和延时状态随结果展示。演示结果来自独立的离线样本。追踪基准、价格线和触发记录按模式保存在当前浏览器。

## 开盘与尾盘买入候选

点击侧栏「开收盘」。开盘策略在交易日北京时间 09:30 至 10:00 运行，从成交额榜单初筛。尾盘策略在 14:45 至 14:57 运行，从主力资金净额榜单初筛，并要求两条相隔至少 20 秒、最多 5 分钟的同一尾盘报价。14:57 进入收盘集合竞价后停止生成新候选。服务端自动采集，不依赖浏览器开着。15:05 后用同日收盘报价复核尾盘候选，最多列出 5 只供次日观察。档案保留最近 40 个交易日的采集状态和最近一次有效排名。当天未运行或数据不全的时段显示相应状态。交易时段参考 [上交所股票投资说明](https://one.sse.com.cn/onething/gptz/) 和 [深交所交易时段说明](https://www.szse.cn/www/investor/knowledge/stock/deal/t20191204_572383.html)。

每轮读取东财榜单首 100 项，最多用腾讯报价复核 32 只，输出最多 8 只。只用当日、距扫描时间不超过 90 秒且位于策略窗口内的报价确认候选。初筛的行情时间和延时状态独立展示。评分按条件权重计算，展开分数可查看明细。表内显示触发价、上浮 0.3% 的价格上限，以及跌破开盘价或尾盘对比基准后的失效参考。没有合格数据或候选时会显示当前状态。演示模式的候选和对比快照均为离线样本。

## 分批计划、小时筛选和模拟交易

- **计划。** 按股票记录每档买卖条件价、股数、预算和备注。行情达到条件后标记触价。成交需手工登记，按移动加权计算含费用的成本、已实现及浮动盈亏，支持撤销末笔及 CSV 导出。买卖记录按日期递增登记。软件检查沪深普通股票当日新增持仓的可卖限制。计划与成交保存在当前浏览器，真实与演示分开。
- **来源参考。** 已核对 [mengmengzhang](https://github.com/1050083883-prog/mengmengzhang/tree/6156a1753913a11036975f411cf7caa78eb1de67) 的多标的分批计划、成交记账、费用测算和行情联动。该提交未提供许可文件。Pulse 的相应功能独立实现，使用既有后端行情。默认的连续下跌翻倍规则、浏览器直连外部新闻接口和原项目代码未纳入安装包。
- **超短线。** 后端按北京时间 10:30、11:30、14:00 扫描，15:00 汇总。用东方财富沪深北 A 股成交额前 100 榜单初筛，最多复核 20 只成交额至少 1 亿元的沪深主板非 ST 股票。腾讯报价核对当前状态，新浪 30 分钟量价计算形态和历史验证。验证按同一股票同一时段，用最近 100 个已有完整次交易日的交易日。下一根 30 分钟收盘价至少为信号价 99%，计入滑点后买入价不高于信号价 100.5%，次交易日 10:00 以半小时线收盘价模拟退出。双边合计约 0.30% 模拟费用和滑点，净收益为正记一胜。要求历史胜率严格超过 80%、至少 30 笔、历史量价及退出覆盖均至少 90%。缺少退出价计入分母。页面另示 95% Wilson 区间下限和未达标原因。该检验使用现有标的的固定规则与可取历史，未对历史时点的全市场候选池、复权事件和实际成交队列做完整重建。
- **模拟交易。** SQLite 持久化初始 ¥1,000,000 的人民币账户，交易日完成分时确认后，按其后的有效卖一报价和可见手数模拟开仓。可卖日用买一平仓，涨跌达到 +3% 或 −2% 时提前核对，剩余持仓从次交易日 10:00 起核对。盘口超过 25 秒、单边盘口、买卖价差超过 0.6% 或可见买盘数量不足时跳过相应成交。滑点 0.10%，佣金 0.05%（最低 ¥5），过户费 0.001%，卖出印花税 0.05%。这些是模拟费率假设，不连接券商。每周目标为 5 笔新开仓，平仓另计。未到周目标时，可以较小仓位验证至少 5 笔历史样本、胜率至少 50%、已知平均净收益为正且覆盖达标的次级信号。次级信号独立标注。没有合规机会时记录缺口。常规总仓位上限 20%，单只达标信号 6%，次级信号 2%；防守时降至 10%、3%、1%。日内核对权益较上次收盘跌至 1% 停止当日开仓。15:00 复盘估值，收盘回撤达到 1.5% 或近十笔胜率低于 55% 启用防守，回撤达到 3% 暂停新仓并继续核对已有持仓。逐笔报告列出信号、盘口价格、费用、平仓原因、持有期间的已观测最优与最差变动和毛净收益拆分。已保存的 2.3 历史成交仍显示其原始记录。历史筛选胜率和盘口执行账户胜率属于不同模型。每日复盘列出周进度、风险配置变动及原因，两类记录均可导出 CSV。
- 小时扫描和模拟账户在本地服务运行期间执行，无需一直打开对应网页。服务关闭、休眠、交易日历未确认或数据不全时，未执行的时点不会伪造历史记录。周目标、胜率、回撤均随真实可用行情和模拟成交更新。交易时段和 T+1 规则见 [上交所股票投资说明](https://one.sse.com.cn/onething/gptz/) 和 [交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/universal/c/c_20260424_10816492.shtml)。

## 全球行情

点击「全球行情」并使用真实模式。覆盖美股主要指数、费城半导体、VIX、美国十年期收益率、美元兑离岸人民币、标普和纳指期货，以及布油、WTI、黄金、铜、天然气、玉米等 15 项。美股盘中行情与最近确认的美东收盘分列。期货使用 Yahoo Finance 近月连续报价，涨跌按上一日线收价。报价逐项显示时间、缓存、延迟或不可用状态。外盘方向需要两项已完成的同日美股指数收盘及两项有效股指期货，作为 A 股盘前观察线索。

请求按品种并发读取并合并共享，成功缓存 45 秒，失败冷却 90 秒。Yahoo Finance 的图表入口可能因网络或源站限制不可达。此时页面显示等待或缓存状态，缺失报价不计入规则。采集行情取决于运行 Pulse 的电脑网络。

## 报价刷新

指数、自选和追踪共用一条订阅连接，换股只更新订阅。服务端合并同时发起的重叠报价请求，缓存命中沿用原采集时间。手动刷新即时发出请求，并复用 3 秒内已取到的报价。WebSocket 中断后页面临时轮询，重连后恢复推送。页面分别展示采集时间与来源行情时间。8 秒是盘中采集目标，端到端时延受数据源与网络影响。

自选范围只用报价字段筛选时直接走共享报价。选择主力净额作为条件或排序时使用东财快照。图表库和较重的研究页独立加载。离开总览时暂停后台图表、快讯和总览面板的轮询，报价订阅和预警仍可使用。

## 数据接口

按 [a-stock-data v3.10.4](https://github.com/simonlin1212/a-stock-data/blob/f21534946c42be3ad048ac938eecb1bad84cb8ab/SKILL.md) 适配。上游文档发布于 2026-11-04，核对的提交为 `f21534946c42be3ad048ac938eecb1bad84cb8ab`。上游 Apache-2.0 许可见 `backend/adapters/LICENSE-a-stock-data`。

| 能力 | 上游与口径 |
| --- | --- |
| 指数、自选、五档 | §1.1 腾讯批量快照，显式区分市场。成交额统一为元，股本市值统一为元。展示上游报价时间。 |
| 分时和 K 线 | §1.2 腾讯多入口切换。K 线成交量保留上游单位，科创板 688/689 为股，其余为手。北交所腾讯 K 线未接入。 |
| 资金榜与成分 | §3.7、§3.8 东方财富 `clist`。排名按带符号主力净额，正为净流入，负为净流出。三种周期的成交额和涨跌广度均为当日口径。10 日领涨股字段未接入。 |
| 个股主力资金 | §3.5、§4.5 东方财富分钟及日级序列。净额为数据源估算，单位元。 |
| 情绪 | 东方财富沪深北 A 股列表及 §8.1 涨停、跌停、炸板、昨日涨停池。全市场广度需要分页，后台取齐且去重后发布，页面显示覆盖量和每项来源。 |
| 资讯 | §5.4 华尔街见闻、§7.1 巨潮公告。 |
| 时段 | §12 深交所自然月完整日历，Asia/Shanghai 时区。日历缺失时，工作日显示待确认，并暂停实时预警。 |

API 定义位于 [http://127.0.0.1:8765/openapi.json](http://127.0.0.1:8765/openapi.json)。原 `/docs` 转至本机 JSON。核心路径如下。

```text
GET /api/market/indices             GET /api/market/sentiment
GET /api/market/global               GET /api/stocks/session-journal
GET /api/stocks/quotes              GET /api/stocks/{code}/kline
POST /api/stocks/screen             GET /api/stocks/buy-candidates
GET /api/stocks/hourly-opportunities  GET /api/paper/account
GET /api/stocks/{code}/fund-flow    GET /api/stocks/limit-up
GET /api/stocks/{code}/announcements
GET /api/sectors/ranking            GET /api/sectors/fund-flow
GET /api/sectors/{board}/roles      GET /api/alerts
GET /api/tail                       GET /api/news
GET /api/system/health              WS  /ws/market
```

每个 HTTP 数据包包含 `data`、`source`、`source_url`、`fetched_at`、`market_time`、`is_stale`、`schema_version`、`error`、`mode` 和 `cached`。缺失值返回 JSON `null`。采集时刻和行情时刻分别展示。东方财富延时路由单独标记，使用排名采集时刻保存变化。未返回交易时间的接口保持其为空。

正常交易时段指数、自选和追踪共用 WebSocket 报价，目标周期 8 秒，休市 45 秒，演示 5 秒。板块资金榜仍按既有频率采集。后端合并同键并发、持久化最近真实成功结果、对东财全局串行并在请求间隔加入抖动。失败时真实和演示数据使用独立缓存。切换同一数据源的已知延时入口时同样限速。预警的低频辅助采集轮换自选，个股资金或日线缺失时跳过相应规则。

SQLite 默认保存在 `.pulse/market.db`。自选、阈值、布局和快讯已读状态保存在当前浏览器。同一页面或标签页保持打开时进行采集与预警。配置参考 `.env.example`。已记录的板块快照按采集时间查询，可用于事后核对当时已知数据。

## 本地服务与账本保护

- 本地启动脚本仅绑定回环地址，API 和报价订阅检查实际连接地址、Host 与浏览器来源。筛选请求和 WebSocket 控制消息有大小及频率限制。页面、脚本和 API 由本机服务提供，外部数据链接仅允许不含凭据的 HTTPS 地址。
- CSV 导出保护可能被表格软件解释为公式的文本字段。数值列保留数值。
- 盘口时间回退、未来报价、集合竞价和异常挂单量不会产生模拟成交。模拟账本写入时核对版本，旧实例生成的过期快照无法覆盖较新的记录。
- 从 2.4 升级时先关闭旧版，再将新版覆盖解压到原目录。原目录的 `.pulse/market.db` 存储模拟账户、复盘和候选档案。旧版虚拟环境的关键依赖版本不足时，启动脚本会联网补齐。

## 指标和评分

- MA5、MA20 为最近 N 根收盘均值。MACD 使用 EMA(12) − EMA(26) 得 DIF，DIF 的 EMA(9) 得 DEA，柱为 2 × (DIF − DEA)。RSI14 使用 Wilder 平滑。样本不足的值为空。
- 板块热度由当日主力净额强度、5 日与 10 日资金同向、当前区间涨跌幅、当日上涨广度、同日上次榜单排名变化组成，权重为 30/25/15/20/10。单项截断到 0–100。有效权重少于 60% 时留空，其余按有效权重重归一。
- 龙头先要求当日跑赢板块且近 5 日收益为正，按板块涨幅分位、成交额分位、近 5 日收益、主力净额分位加权。中军要求流通市值与成交额均达到成分中位数，另纳入近 20 日与其余有效样本等权收益的 Pearson 相关性。低位补涨要求近 5 日落后样本均值、收盘处近 20 日高低区间 55% 以下、量比至少 1、主力净额高于此前两条均值、成分样本相关性至少 0.25。
- 角色先读实际成分，再对成交额前 8 和涨幅前 4 去重取历史，补涨资金核对其中涨幅后 4。角色评分需要对应字段齐全。UI 展示实际覆盖、权重和单项分。按板块打开后按需计算。
- 市场情绪采用上涨广度、涨停占涨跌停比例、封板率和昨日涨停今平均涨幅，权重为 45/25/20/10。封板率为涨停家数除以涨停和炸板家数之和。有效权重低于 65% 时不计算总分。
- 尾盘观察分由尾段价格变化 65% 与尾段成交额占比 35% 加权，最少需要同日两次尾盘快照。预警以来源时间为准，单标的同类信号静默 5 分钟。资金突变为相邻累计净额绝对差达到 2,000 万元，持续流入为连续三段累计净额递增。板块涨幅突变为相邻快照差至少 1.2 个百分点，排名跃升为至少 5 位。个股偏离规则要求已核对板块成员资格。
- 评分用于解释观察依据。当前快照记录可回看，独立策略回测和逐笔竞价源未接入。
